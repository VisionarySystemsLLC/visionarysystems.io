# Brand assets

Rendered by `tools/og.py` from the same mark, fonts, and colors as the site, so they stay in step with it.

- `reddit-banner-1600x480.png`: the profile banner to upload. The new profile page shows a 10:3 banner whole; it scales a 5:1 banner to height and crops it from the left, which cut the old lockup. The lockup sits in the middle band so a wider surface that crops top and bottom keeps it. Ion blue (#5CE1FF) stars join the gold ones, matching the site.
- `reddit-banner-1920x384.png`: the same composition at the old 5:1 size, for layouts that still use it.
- `reddit-avatar-512.png`: the mark alone on the mark field (#0A1020), content within the central 80%, a few faint stars.

Palette: navy #0A1628 / #132340 (mark field #0A1020), gold #FFB830 (#DE9A00 on light), ion blue #5CE1FF, off-white #EEF2FF, slate #8B9AAD. Type: Spectral, with Spectral SC for small-caps labels. The original kit (mark SVGs, lockups, the observer avatar) is unchanged by this folder.
